Migrate Amazon Clone to a Portfolio-Ready React Application

This plan outlines the step-by-step process for converting the static HTML/JS Amazon Clone into a dynamic, enterprise-grade React application using Vite. This structure is designed to showcase skills recruiters actively look for (Redux Toolkit, clean architecture, routing, and optional backend integration).

User Review Required
IMPORTANT: This plan includes advanced features like Redux Toolkit and optionally Firebase/Stripe to make it stand out to recruiters.

Git Repository Setup 
Your current folder (h:\Coding\Amazon-Clone) is not yet a Git repository. Task 1 will initialize Git.

Handling Old Files 
We will move existing .html, .css, and .js files into a legacy_html folder to act as a reference while building the new React version.

Open Questions
- Should we use TypeScript or stick to plain JavaScript? (TypeScript is highly recommended for portfolios).
- Do you want to integrate real Authentication (e.g., Firebase) or keep it mock?
- Do you want to add Stripe for payment processing (highly impressive for e-commerce clones)?

Proposed Changes (Portfolio Edition)

Task 1: Project Setup & Architecture
- Initialize Git repository.
- Move existing legacy files to `legacy_html/`.
- Scaffold a new React app using Vite.
- Set up a scalable folder structure (`src/components`, `src/features`, `src/pages`, `src/services`, `src/assets`).
- Milestone Commit: "Task 1: Initialized Git and setup Vite React template with structured architecture"

Task 2: Asset Migration & UI Foundation
- Move images to `public/`.
- Migrate global CSS and implement a standardized CSS system (BEM or CSS Modules).
- Set up global variables (colors, fonts) to match Amazon's design system.
- Milestone Commit: "Task 2: Configured assets and foundational CSS system"

Task 3: Layout & Routing
- Install `react-router-dom`.
- Build reusable Layout components: `Header`, `Footer`.
- Set up basic routes: `Home`, `Checkout`, `Login`.
- Milestone Commit: "Task 3: Implemented Layout components and React Router"

Task 4: Global State Management (Redux Toolkit)
- Install `@reduxjs/toolkit` and `react-redux`.
- Setup the Redux store.
- Create a `cartSlice` to handle: adding items, removing items, updating quantities, and calculating totals.
- Create a `userSlice` to handle authentication state.
- Milestone Commit: "Task 4: Integrated Redux Toolkit for Cart and User state"

Task 5: Dynamic Data & Products
- Build the `ProductCard` component.
- Create a mock API service or JSON file for products.
- Render products dynamically on the `Home` page.
- Connect `ProductCard` "Add to Basket" buttons to the Redux store.
- Milestone Commit: "Task 5: Built dynamic product listing connected to Redux"

Task 6: Authentication (Firebase)
- Integrate Firebase Auth.
- Build the `Login` and `Register` pages.
- Connect authentication state to the Redux `userSlice`.
- Milestone Commit: "Task 6: Implemented Firebase Authentication"

Task 7: Checkout & Order History
- Build the `Checkout` page displaying the cart items from Redux.
- (Optional) Integrate Stripe for test payments.
- Milestone Commit: "Task 7: Built Checkout process and Cart total calculations"

Task 8: Final Polish, Animations & Deployment
- Add micro-animations (hover effects, toast notifications for adding to cart).
- Ensure fully responsive design for mobile, tablet, and desktop.
- Cleanup legacy files if no longer needed.
- Milestone Commit: "Task 8: UI polish, responsive checks, and cleanup"
